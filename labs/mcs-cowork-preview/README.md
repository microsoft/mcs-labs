# From a question to a working app

This unlisted preview explores a shorter, mission-based format for a Cowork lab. It is not an official product guide and uses fictional Fabrikam data and mock product screens.

## 🧭 Lab Details

| Level | Persona | Duration | Purpose |
| ----- | ------- | -------- | ------- |
| 200 | Business User | 30 minutes | Explore four missions: ask a document-grounded question, delegate work, connect CRM data, and build a small app. |

## Preview missions

1. **Ask** — Find an answer grounded in a document.
2. **Delegate** — Create a useful report from a collection of mock documents.
3. **Connect** — Use mock CRM data through a plugin.
4. **Build** — Create a small app against a mock Dataverse table.

All names, records, interfaces, and outputs are fictional. Share feedback on the learning format, pacing, and clarity rather than treating the mock steps as product instructions.
