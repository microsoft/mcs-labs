## Declarative agents

Declarative agents extend Copilot Chat with a focused role, instructions, knowledge, and capabilities. This module covers the **Copilot Chat harness**, not the separate **Microsoft Copilot harness** used for the reasoning-heavy agents and workflows in later labs. The **Standard harness** is also a separate option.

Compare the authoring paths in Agent Builder, Microsoft 365 Agents Toolkit, and Microsoft Copilot Studio. In the companion lab, reuse a skill in Agent Builder and ground the agent in a supplied report.
