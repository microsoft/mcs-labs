## Overview

The Copilot Agent Kit is a comprehensive set of capabilities designed to augment Microsoft Copilot Studio. The kit helps makers develop, govern, and test custom agents, use a large language model to validate AI-generated content, optimize prompts, and track aggregated key performance indicators of their custom agents.

## Topics covered

- Developing, governing, and testing custom agents.
- Using a large language model to validate AI-generated content.
- Optimizing prompts.
- Tracking aggregated agent key performance indicators.
