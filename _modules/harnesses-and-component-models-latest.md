## Keep the harnesses distinct

The **Copilot Chat harness** supports declarative agents that extend Microsoft Copilot. The **Microsoft Copilot harness** used in the refreshed labs was previously labelled **GitHub Copilot**; older documentation and interface labels can still use that name. Neither is the **Standard harness**.

The **Customer Conversation harness** supports customer-facing chat and voice experiences. Choose a harness for the required behavior, channels, tools, and governance rather than treating the names as interchangeable.
